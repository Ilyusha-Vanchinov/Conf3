# УВМ — вариант 6. Ассемблер и интерпретатор

## Общее описание

Проект реализует ассемблер и интерпретатор для учебной виртуальной
машины (УВМ), вариант 6. Работа выполняется поэтапно; каждый этап
фиксируется отдельным коммитом в git-репозитории.

Текущее состояние: **этап 1** — CLI-ассемблер, который разбирает
текстовый файл программы на языке ассемблера и строит промежуточное
представление (список инструкций). Генерация машинного кода и
интерпретатор будут добавлены на следующих этапах.

## Структура репозитория

```
.
├── README.md
├── .gitignore
├── run.bat
├── requirements.txt
├── src/
│   ├── __init__.py
│   ├── isa.py
│   └── assembler.py
├── tests/
│   ├── __init__.py
│   └── test_assembler.py
└── examples/
    └── spec_tests.asm
```

- `src/isa.py` — описание системы команд УВМ: коды операций,
  допустимые диапазоны операндов, класс `Instruction`.
- `src/assembler.py` — CLI-ассемблер: разбор `.asm` в промежуточное
  представление и режим тестирования.
- `tests/test_assembler.py` — модульные тесты ассемблера.
- `examples/spec_tests.asm` — тестовая программа из спецификации УВМ.
- `run.bat` — скрипт запуска для Windows.

## Язык ассемблера

Синтаксис строки:

```
мнемоника операнд
```

Правила:

- комментарий начинается с символа `;` и продолжается до конца строки;
- пустые строки игнорируются;
- мнемоники регистронезависимы;
- операнд — целое число в десятичной (`463`) или шестнадцатеричной
  (`0x1CF`) форме.

Поддерживаемые команды:

| Мнемоника    | Код A | Операнд B    | Диапазон B       |
|--------------|-------|--------------|------------------|
| `load_const` | 41    | константа    | 0…8191           |
| `load_mem`   | 25    | адрес памяти | 0…33 554 431     |
| `store_mem`  | 49    | смещение     | 0…255            |
| `sub_mem`    | 30    | адрес памяти | 0…33 554 431     |

## CLI ассемблера

```
python -m src.assembler <source.asm> <output.bin> [--test]
```

Аргументы и настройки:

- `source.asm` — путь к исходному файлу программы на языке ассемблера;
- `output.bin` — путь к бинарному файлу-результату. На этапе 1 файл
  не формируется; аргумент принимается для совместимости с CLI
  следующих этапов;
- `--test` — включить режим тестирования: вывести промежуточное
  представление программы в виде полей `A` и `B`.

## Режим `--test`

В режиме тестирования для каждой команды печатается строка:

```
<МНЕМОНИКА>: A=<код>, B=<операнд>
```

Это соответствует тестам из спецификации УВМ: демонстрирует, что
ассемблер строит внутреннее представление с теми же полями и
значениями.

## Пример использования

Файл `examples/spec_tests.asm`:

```asm
; Тестовые команды из спецификации УВМ (вариант 6)
load_const 463
load_mem 1002
store_mem 122
sub_mem 993
```

Запуск в Windows:

```
run.bat assemble examples\spec_tests.asm out.bin --test
```

Эквивалентная команда без `run.bat`:

```
python -m src.assembler examples/spec_tests.asm out.bin --test
```

Ожидаемый вывод:

```
LOAD_CONST: A=41, B=463
LOAD_MEM: A=25, B=1002
STORE_MEM: A=49, B=122
SUB_MEM: A=30, B=993
```

## Сборка и запуск тестов

Требования:

- Python 3.10 или новее;
- `pytest` (устанавливается из `requirements.txt`).

Установка зависимостей:

```
pip install -r requirements.txt
```

Запуск тестов в Windows:

```
run.bat test
```

Эквивалентная команда без `run.bat`:

```
python -m pytest tests/ -q
```
